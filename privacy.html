Roomy Privacy Policy

This Privacy Policy describes how Roomy, developed by Hamelot Games, accesses, uses, and protects information when users choose to use supported online integrations, including Google and YouTube.

Google and YouTube Integration

Roomy provides optional integration with Google and YouTube services. A user may choose to connect their Google account in order to enable YouTube livestream features.

Roomy may request access to Google or YouTube information required to identify supported YouTube livestreams, access supported livestream information, and read supported YouTube live chat activity.

This information is used to provide features such as allowing YouTube livestream chat commands to interact with Roomy activities.

How Google User Data Is Used

Google user data accessed by Roomy is used only for providing the YouTube integration requested by the user.

Roomy does not use Google user data for advertising.

Roomy does not sell Google user data.

Roomy does not use Google user data to create advertising profiles or for unrelated purposes.

Authentication Information

Roomy uses Google's OAuth authorization system to allow users to authorize access to supported YouTube features.

Authentication tokens required to maintain the user's authorized connection may be stored locally on the user's device.

Roomy does not request or store the user's Google account password. Authentication is performed directly through Google's authorization system.

YouTube Live Chat Data

When YouTube integration is active, Roomy may temporarily process information obtained from YouTube live chat, including information required to identify chat participants, chat messages, and supported commands.

This information is used to perform requested livestream interaction features within Roomy.

Sharing of Google User Data

Hamelot Games does not sell Google user data.

Google user data accessed through Roomy is not shared with third parties except when required to provide the requested functionality, comply with applicable law, or protect the security of the application and its users.

Data Retention

Roomy is designed to access Google and YouTube information only as necessary to provide the connected features.

Locally stored authentication information may remain on the user's device until the user disconnects the integration, removes the associated Roomy configuration data, or revokes Roomy's access through their Google account.

Revoking Google Access

Users may revoke Roomy's access to their Google account at any time through their Google Account security and third-party connection settings.

Users may also disconnect YouTube integration from within Roomy's Stream Settings where supported.

Google API Services User Data Policy

Roomy's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Children's Privacy

Roomy's Google and YouTube integration is not designed for collecting personal information from children.

Changes to This Privacy Policy

Hamelot Games may update this Privacy Policy when features or data practices change. The current version will remain available on this page.
