Roomy

A customizable virtual room and avatar experience by Hamelot Games.

About Roomy

Roomy is a customizable virtual room and avatar application developed by Hamelot Games. Players can create and customize rooms, use avatars, interact with objects, participate in activities, install additional content, and use streaming integration features.

Roomy is available for PC through Steam and other supported distribution platforms.

YouTube Integration

Roomy includes optional YouTube integration designed for livestreamers. Users may connect their Google/YouTube account to allow Roomy to interact with supported YouTube livestream features.

When YouTube integration is enabled, Roomy may access information required to locate an authorized user's livestream and read supported live chat activity so that viewer commands can interact with Roomy.

For example, livestream viewers may be able to use supported chat commands to participate in Roomy activities such as Battle Royale.

Connecting a Google or YouTube account is optional. Roomy can be used without enabling YouTube integration.

Google User Data

Roomy only requests Google or YouTube permissions required for the features selected by the user. Google user data obtained through these permissions is used only to provide Roomy's YouTube integration.

More information about how Roomy handles Google user data is available in our Privacy Policy.
